# DeskTabs: Neu in dieser Version
<!-- Pro Version ein Abschnitt "## x.y.z", darunter kurze Punkte "- ...". Zentrale Wörter **fett**. DeskTabs zeigt sie nach einem Update an (neueste zuerst). -->

## 1.1.13
- **Updates mit einem Klick:** Ist eine neue Version da, gleitet über der Taskleiste ein Hinweis heraus. **Jetzt aktualisieren** lädt, prüft und installiert sie, DeskTabs startet danach neu.
- **Was ist neu:** Nach jedem Update zeigt dieses Fenster die Neuerungen. Später wieder aufrufen: **Hilfe → Neu in dieser Version**.
- Den **Update-Hinweis abschalten** kannst Du unter Weitere Einstellungen.

## 1.1.12
- **Unterprojekte** für Sammel-Desktops: **Klick auf den aktiven Tab** öffnet eine kleine Auswahl, **Alt + Klick** das volle Menü zum Anlegen und Entfernen. Das Unterprojekt steht klein im Tab und als eigene Spalte im **Zeit-Log**.
- Alle **Menüs im Windows-11-Stil**.
- Ein Klick auf den aktiven Tab öffnet **nicht mehr die Taskansicht**.
- **Behoben:** Die Leiste verschwand mit dem Startmenü, ein Umsortieren konnte hängen bleiben, der Name zuckte beim Neuaufbau.
