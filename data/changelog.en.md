# DeskTabs: what's new
<!-- One section "## x.y.z" per version with short points "- ...". Key words in **bold**. DeskTabs shows them after an update (newest first). -->

## 1.1.13
- **One-click updates:** when a new version is out, a notice slides out above the taskbar. **Update now** downloads, checks and installs it, then DeskTabs restarts.
- **What's new:** after every update this window shows the changes. Open it again any time: **Help → New in this version**.
- You can **turn the update notice off** under More settings.

## 1.1.12
- **Sub-projects** for catch-all desktops: **click the active tab** for a small picker, **Alt + click** for the full menu to add and remove them. The sub-project shows in small type in the tab and as its own column in the **time log**.
- All **menus in the Windows 11 style**.
- Clicking the active tab **no longer opens Task View**.
- **Fixed:** the bar disappeared with the Start menu, a reorder drag could get stuck, the name twitched when the bar was rebuilt.
